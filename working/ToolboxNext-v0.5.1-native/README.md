# P011 原生风格工具箱 v0.5.1 — 独立限时试用版

沿用 P011 的黑底、青绿色、大图标和大字号，使用设备已有 Qt 5.10.1、Wayland、系统字体。原厂 Z03 始终继续运行；退出只关闭自己的窗口、后端和播放器。**不是固件或常驻安装，不修改原厂菜单/启动脚本。** 仅适用于已经核验的 v2.4.0，旧系统不能绕过预检。

## 三个模块

| 模块 | 功能 | 边界 |
|---|---|---|
| 文件中心 | 六类目录、分页、图片与 UTF-8 TXT 预览、点击音视频播放、无线传输入口 | 不浏览系统目录，不删除/覆盖文件；TXT 前 64 KiB；媒体格式依赖目标解码插件 |
| 无线传文件 | 手动开启、同一局域网网页上传/下载、临时访问码、10 分钟关闭 | 仅 Wi-Fi/以太网私网 IP；HTTP 无加密，只用于可信局域网；单文件 64 MiB |
| 小游戏 | 贪吃蛇、2048、打砖块；暂停、重来、最高分、返回 | 两端控制，中间 480×192；方向键 136×92；打砖块两端各 136×192，按住移动或拖动挡板；无模拟器/ROM |
| 仪表盘 | CPU、内存、空间、网络速率、运行时间、只读进程、曲线和导出 | 约 2 秒采样、最多 300 点、显示最近 120 点；缺失值留空；不读进程命令行/环境变量 |

用户目录为 /mnt/data/p011-toolbox/user，其下 Music、Pictures、Text、GameResources、Screenshots、Exports 是文件中心唯一开放范围，不等于原厂全部文件。游戏资源只保存，不解压或执行；截图目录用于浏览已有文件，不提供全系统截屏。

## 双击入口

- **RUN_NATIVE_TRIAL.cmd**：电脑只连接一台正常 ADB 的 P011 后双击，打开最多 10 分钟的独立界面。首页“退出”可提前关闭，USB 断开不影响设备端限时监督。
- **COLLECT_NATIVE_RESULTS.cmd**：退出后收集原始 stdout/stderr、结果、工具箱截图和 ZIP；未结束只报告仍在运行。
- **STOP_NATIVE_TRIAL.cmd**：请求停止最近一次试用并收集。只写本会话停止标记，不向原厂发信号。强制停止可能使 UI 退出码非零，应查看组件关闭和原厂身份，不把请求当成完成。
- **SMOKE_DEVICE.cmd**：显式执行真机自动化冒烟，约 15 秒；监督上限约 30 秒加清理余量。使用会话专属合成文件，不污染正式用户内容，不自动开启 LAN 或播放声音。
- **PREVIEW_PC.cmd**：电脑 800×268 Qt 预览，不调用 ADB。
- **VERIFY_HOST.cmd**：电脑 Python、Node、Qt 交互及可用时 WSL 测试，生成日志/截图/源码哈希/ZIP，不调用 ADB。

电脑运行需要 Python 3.8+ 与 ADB。完整主机测试另需 PyQt5、Node.js；Linux 专属路径门禁由本机 kali-linux WSL 验证。设备不需要 PyQt、完整 json/http.server/socketserver/fcntl/resource，也不使用 Android/APK、apt 或新系统服务。

## 环境补齐范围

兼容 JSON、受限 HTTP、Qt 启动/监督助手只放在 /mnt/data/p011-toolbox/candidates/native-051-<hash>。复用已有 Qt Quick Test 的入口形成独立限时窗口，没有添加/替换系统 Qt、Python 或字体，没有写开机自启。源码清单决定路径；已有候选必须逐文件匹配，否则停止。

会话日志留在 /mnt/data/p011-toolbox/sessions/<run>，退出后保留排查；不会自动批量删除候选或用户内容。会话令牌只驻留内存，经限时一次性回环握手交给 QML，LAN 无该接口，不开放 CORS、任意 shell 或 WebChannel 命令。

源码包不包含厂商固件/二进制/字体/图标、用户文件、访问码、密钥或 NV/校准。

## 验证边界

已在 P011 v2.4.0 / Python 3.5.5 / Qt 5.10.1 验证三页、真实 TXT/PNG 预览、三个游戏、开始/暂停、打砖块按住侧键、实时系统采样。退出后核对原厂三个文件、五个服务及原厂父进程身份，并确认工具箱窗口/线程/端口关闭。用户先确认显示与点击正常，改版后再次确认“大按钮大小和布局合适，操作正常”。

本版主机测试 35 项：Windows 32 通过、3 项 POSIX 专属跳过；WSL Linux 35 项通过；另有 12 项游戏规则及 Qt 页面/按钮测试。最终证据以随包报告及原始结果为准。

**仍未验收**：手机至笔真实 LAN 传输、新固件真实音视频/自然结束、长时稳定性、原厂所有业务、永久菜单入口。自动点击不冒充触摸，主机网页测试不冒充手机连笔，旧版音频成功也不冒充本版声音验收。旧工具箱和 v0.5.0 包保持不动，不自动运行旧 START。
