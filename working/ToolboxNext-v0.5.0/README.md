# P011 Toolbox Next v0.5.0 — 第一版扩展候选

**功能已实现，电脑/浏览器验证及 P011 隔离后端自检通过；尚未接入笔上原厂菜单，不是刷机包。** 原有工具箱、原厂程序、启动脚本、无线电配置均未替换。适用目标是升级后的 v2.4.0，不能运行旧 v2.1.2 的 START。

## 第一版内容

| 模块 | 已实现 | 边界 |
|---|---|---|
| 文件中心 | 限定目录、分页、图片/UTF-8 文本预览、点击音频/视频播放、截图文件浏览 | 不开放系统盘，不提供删除/覆盖；截图文件可以查看/导出，本版不新增全屏截图采集 |
| 无线传文件 | 手机/电脑网页、批量上传进度、真实下载、8 位临时访问码、600 秒到期关闭 | 笔上手动开启，仅当前 Wi-Fi/以太网 RFC1918 地址；HTTP 无加密，只用于可信局域网；单文件 64 MiB |
| 小游戏 | 贪吃蛇、2048、打砖块；触摸/滑动/方向键、暂停、重来、最高分、快速返回 | 最高分按正常保存持久化；不保存整盘游戏进度，不内置 ROM 或模拟器 |
| 系统仪表盘 | CPU、内存、盘空间、按接口网络速率、运行时间、只读进程；CPU/内存曲线；采样/简化事件日志导出 | 每约 2 秒采样，内存中最多 300 点；曲线最近 120 点；缺失值留空，不读取进程命令行/环境变量 |

指定用户目录 `/mnt/data/p011-user` 下有 `Music`、`Pictures`、`Text`、`GameResources`、`Screenshots`、`Exports`。游戏资源只存储，不执行、不解压。文本最多预览前 64 KiB；图片和媒体是否可解码取决于目标 Qt/GStreamer 插件，扩展名白名单不等于全部格式实测支持。

音频沿用第四轮的 `gst-play-1.0` 实际位置方案，不导入旧无线电/SSH 后端；准备时保持 0，播放代号使用 `double`，轮询只有一个在途请求。新固件上的真实声音、视频、自然结束仍需独立物理验收。原始音频 stdout/stderr 留在隐藏状态目录，不会自动放进无线分享列表；普通“导出日志”只导出不含路径/访问码的事件摘要。

## 双击入口（均为电脑操作）

- `PREVIEW_PC.cmd`：打开 800×268 Qt 预览，用电脑临时目录里的合成示例。需要本机 Python 和 PyQt5；没有自动安装依赖。电脑预览不会连接 ADB。
- `VERIFY_HOST.cmd`：Python 后端测试、Node 游戏规则、Qt 实际组件与按钮/预览检查；已装 kali-linux 时追加 WSL Linux 路径隔离测试。自动生成逐项 stdout/stderr、退出码、截图、源码哈希和结果 ZIP；**不调用 ADB**。

电脑依赖：Python 3.8+（开发机实测 3.12）、Node.js、PyQt5。Qt 预览实测使用 Qt 5.15.2，不能当作目标 Qt 5.10.1 的 UI 验收。主机缺少可加载的 QtMultimedia QML 插件时，视频单独提示错误，其余模块照常工作；离屏截图只引用电脑现有系统字体，包里没有字体文件。

目标后端只需固件已有 Python 3.5.5；自带输出型 `p011_json.py` 和有界 HTTP 子集，不依赖目标缺失的 `json/http.server/socketserver/fcntl`。不使用 Android/APK、apt、原厂 D-Bus、ConnMan、BlueZ 或任意 shell 接口。

## 验证分层

- Windows 后端 27 项：26 通过、1 项 Linux 专属符号链接测试跳过；WSL Linux 同样 27 项全部通过。
- Node 游戏规则 12 项通过。
- Qt 主机实测：三个页面加载，图片实际解码，中文 TXT 实际显示，开始/暂停按钮生效，返回正常；大于 32 位的播放代号保留完整。
- Chromium 真实网页：上传成功、下载事件及保存成功、下载 SHA-256 一致、重复上传 409 拒绝、390px 无横向溢出、无未捕获脚本错误。测试是 PC 回环合成文件，不冒充手机连接学习笔。
- P011 v2.4.0：有界 HTTP 和全部后端模块在真实 Python 3.5.5 运行；限定临时目录的中文文件/符号链接拒绝/最高分/采样导出/带认证回环接口通过。只创建明确归属的临时文件，测试后清理；原厂三个文件哈希和 Z03/control_engine 的 PID/starttime 未变。
- **未完成的验收**：v2.4.0 菜单挂载、笔上新 UI/触摸、手机到笔的实际 LAN 传输、真实音视频/长时间运行和正常退出后的原厂物理功能。
