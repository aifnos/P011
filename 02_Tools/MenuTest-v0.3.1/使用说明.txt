P011 原厂菜单一键测试 v0.3.1
========================

这次测试的是“原厂菜单追加工具箱”，不是独立 PlayLab。
固定设备固件：z031_v2.1.2-20221124_143128-user；需要已经可用的 root ADB。

【使用方法】
1. 把整个 ZIP 解压到 D:\project\P011。
2. 学习笔正常开机，回到主页，连接 USB；关闭 PlayLab；只连接这支笔。
3. 打开 P011-MenuTest-OneClick 文件夹，双击 START.cmd。
   不用复制命令，不用管理员权限，不用输入 TESTMENU，不用分别跑 Check / Trial。

自动进行：检查完整包 → 定位现有 adb → 检查设备和原厂哈希 → 备份原版 → 构建候选
→ 部署临时文件 → 校验真实父子进程 → 8 秒倒计时（Esc 取消）
→ 笔端监督进程先启动 → 暂停原厂重启循环 → 请求原厂界面退出 → 候选运行 180 秒
→ 结束候选 → 恢复原厂进程 → 拉取日志和工具箱截图 → 生成结果 ZIP → 打开 ZIP 所在位置。
首次复制到 D:\project\P011\packages 的版本化目录，不覆盖原来的 MenuLab、PlayLab。
如果已经有一个测试在运行，第二次 START 会停止；不要并行测试。

【笔上要做的事】
流程是自动的，但不是机器人自动点击菜单：
在主菜单滑到最右侧，“设置”后面找“工具箱”（暂时复用设置图标）。
依次打开时钟、计时器、设备信息；测试计时器开始/暂停/重置及返回。
返回主页，切换另一种主菜单模式，再打开工具箱。
没有点击某页，结果只记“未观察到”，不会冒充通过或失败。
180 秒到时，正常情况下自动恢复原厂界面，工具箱入口消失。这是预期的临时测试结果。

【结果在哪】
D:\project\P011\results\P011-MenuTest-Run-日期时间.zip
详细工作文件：D:\project\P011\logs\MenuTest-Run-日期时间\
最后结果路径：D:\project\P011\LAST-RESULT.txt

完成后上传这一个 ZIP 给当前对话即可，不用手抄日志。
ZIP 包含：结果摘要.txt、summary.json、index.html、page-events.csv、原始 adb 输出及退出码、
设备 inspection/trial/candidate/worker/guardian 日志、可取得的工具箱页面 PNG。
index.html 是离线结果页面及图片相册；没有网络脚本。
只打包日志和截图，不重复打包原厂 ELF、候选 ELF 或固件镜像。
工具不会自动上传。原厂日志可能含设备标识、账号和网络内容，分享前检查。

【自动截图】
截图调用自定义工具箱自己的 Qt Item.grabToImage：进入/切换页面、操作计时器、每 10 秒尝试抓取。
每个候选进程最多 32 次；顶栏“截屏”可手动触发。
截图只包含工具箱元素，不是物理面板截图，不包含原厂主页、其他窗口或完整桌面。
进入工具箱以前、图形接口不支持或保存失败时没有图片；错误仍进日志。
这条 Qt 截图路径是本版本新增，未在 P011 上实测；PlayLab 的 SDL 截屏成功不等于本路径已成功。

【黑屏或提前结束】
双击 STOP.cmd：仅对本次会话请求停止候选和恢复原厂，再打包日志。
双击 COLLECT.cmd：不开始新测试，仅取回上次已记录会话的日志并重新生成结果包。
如果电脑窗口被关掉，笔端监督程序仍负责到时恢复；重新连接 ADB 后用 COLLECT.cmd。
设备重启会丢失 /tmp 的会话数据，所以优先在重启前取回日志。
内核卡死或监督进程也被终止时不能保证恢复。完全无响应时按正常方式重启，不刷写或格式化。

【边界】
原版 /usr/bin/Z03、原厂启动脚本、ADB 配置均不覆盖；不重挂载、不刷机、不永久安装菜单。
候选代码仍访问真实设备服务和普通应用数据，不是用户数据快照或沙箱；可能联网、更新配置。
测试前结束通话/录音/扫描，测试中不升级、不恢复出厂、不改 ADB/测试服。
检查哈希、路径或启动进程不匹配时停止并保存记录；不会随便清理别人的锁或目录。
START/STOP/COLLECT 批处理只对自己的 PowerShell 子进程设置执行策略，不修改系统持久策略、驱动签名或内存完整性。
Windows 安全功能或组织策略阻止运行时保留提示，不关闭这些保护强行运行。

【ADB 定位】
优先使用 PATH 中已经存在的 adb.exe；也识别
D:\project\P011\tools\platform-tools\adb.exe 和 D:\project\P011\platform-tools\adb.exe。
本包不捆绑 ADB、不联网下载工具。你目前能够执行 adb 的环境通常不需任何额外安装。

【测试情况】
设备端监督代码通过本轮 Linux 主机的 10 项模拟进程恢复测试。
已检查目标 Python 3.5 语法、固定资源块未变化、页面及包内哈希、仅工具箱截图的输出目录。
Windows 一键启动器及这版原厂候选菜单仍需实机验证；详见 tests/oneclick-validation.json。
没有把主机模拟测试当成 P011 菜单/图形实测。


【v0.3.1 修复】
用户 23:51 的实际返回使用 CRCRLF（\r\r\n）；旧版只允许一个 CR，身份检查误停。
新版仅对 shell 文本副本规范化行结束符，原始 stdout/stderr 不覆盖。
每次 shell 命令使用独立退出标记；必须唯一、位于最后、退出码有效，且 adb 本身成功。
非零退出码、缺失/重复标记、传输错误仍会停止；不会取消 root/固件/父进程安全检查。
启动前自动进行 22 项无设备 I/O 的解析自检；结果写入 host-parser-selftest.json。
每条命令新保存 *-stdout-normalized.txt 和 *-remote-status.json。
页面未运行时显示“未测试”，不再暗示全部页面故障；本轮未切换时明确显示 NOT_SWITCHED。
QML、资源补丁、设备端暂停/恢复/超时程序与 v0.3 逐字节相同。
本修复不修复尚未测试到的原厂候选菜单功能；真正界面测试仍待本次执行。
