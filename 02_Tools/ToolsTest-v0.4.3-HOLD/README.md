# P011 工具箱测试版 v0.4

本包在已验证的原厂菜单候选基础上，提供 ADB 配置、电池、无线电、浏览器、影音、SSH 六个入口，对应五类工具。不覆盖原版 `/usr/bin/Z03`，不修改启动脚本，不使用刷机模式。此版仍是限时试验，不是开机常驻安装。

## 使用

将整个 `P011-Tools-Test` 文件夹解压到 `D:\project\P011`，正常开机、停在主页并连接已开启 root ADB 的学习笔。关闭旧 PlayLab / MenuTest，结束录音、通话和扫描。

双击 `D:\project\P011\P011-Tools-Test\START.cmd`。

程序自动核对文件与设备，生成候选、部署自己的文件，倒计时 8 秒后临时切换原厂界面。按 Esc 可取消。测试窗口为 **600 秒**，设备端监督进程负责结束试验与恢复。不要关闭窗口，也不要在试验期间重启、关机、升级或恢复出厂。

菜单横向滑到最右端，在原有“设置”后打开“工具箱”。新页继承原厂 800×268 内容区域、左右手变换、深灰背景、青绿色强调色和本机字体，不另加屏幕旋转。

- `START.cmd`：检查、启动十分钟试验、回退、收集结果。
- `STOP.cmd`：提前结束本次试验、请求恢复原厂、取回结果。
- `COLLECT.cmd`：只取回上一轮会话资料，不重新切换界面。
- `SSH-USB.cmd`：笔上开启 USB SSH 后，建立临时 ADB 转发，以公钥进行 SSH 身份/内核查询，结束后删除本次转发。
- `SSH-LAN.cmd`：笔上开启 Wi-Fi SSH 后，以公钥测试局域网 SSH 登录。电脑必须能访问该 Wi-Fi 地址。为可信固定主机公钥，初次测试仍需 ADB 连接。

## 六个页面

### ADB 调试

免工程密码保存 `debug=1 / 0`，显示保存值与当前 `adbd` 进程是否存在。按钮只修改原厂 USB 配置的 debug 字段，保留文件其余字节。本轮 **不重启、不停止 adbd、不热切换 USB**；退出试验时恢复最初配置。设置页的“保存关闭”是下次启动配置，不是当前连接已断开。

允许立即恢复原配置。若配置在试验中被其他程序改变，恢复器报告冲突，不覆盖他人的变化。请不要趁测试窗口重启，否则可能将关闭配置用于下一次启动；原厂隐藏页密码仍是备用入口。正式即时开关和常驻安装不在本试验内。

### 电池信息

概览电量、充放电状态、电压、电池侧电流、温度、曲线；详情列出驱动提供的容量、电荷、循环数、健康标记、充电器相关字段及原始来源。曲线保留最近 120 个有效/缺失样本，空值不会填零。采样约每两秒，命令耗时可能延长间隔，日志同时带单调时间。

Linux 标准字段按微伏、微安、十分之一摄氏度等换算。功率是电池侧计算值，不是 USB 充电器输入功率；`health=Good` 不是容量健康度 100%。驱动不提供的字段显示“未提供”，不根据机型猜数据。

### 无线电信息

Wi-Fi、4G/网络、蓝牙三页，可显示数据来源。优先读取 ConnMan、oFono、BlueZ D-Bus；Python D-Bus 不可用时使用已存在的有限只读命令回退。包括实际返回的名称、IP、状态、质量、接口收发量、已缓存蓝牙设备/服务等。后台约 12 秒刷新；不主动扫描、配对、断网或改射频配置。

RSRP/RSRQ/SINR/Band/EARFCN/PCI/邻区没有从当前已验证通用接口获得时明确标记未提供。非 Wi-Fi 接口列表可能包含 USB/虚拟接口，不等同于全是蜂窝接口；计数也不代表运营商套餐余额。ConnMan/oFono 的 0～100 信号质量不冒充 dBm。蓝牙 RSSI 可能是缓存值。

### 浏览器

复用 QtWebEngine 1.4 / Qt 5.10.1：地址输入软键盘、前进后退、主页、刷新/停止、缩放、本次会话书签和展开视图。默认加载随包本地页面，可点按钮检查 JavaScript。输入含空格时作为搜索词提交 Bing；访问互联网前需笔上确认，不自动联网测试。

独立 off-the-record profile，不导出原厂 WebChannel/命令桥；拒绝证书错误、相机/录音/定位请求和新弹窗，不自动下载文件。不添加 `--no-sandbox` 或忽略证书的参数。但宿主仍是已有 root 原厂进程/旧版内核，不是已经完成低权限隔离的安全通用浏览器。只浏览可信站点，不登录重要账号。设备时间不正确会引发 HTTPS 失败，程序不会自动改时间。

联网后关闭该页的自动截图；手动“截屏”仍会保存当前网页，分享前检查隐私。书签只保留在本次工具箱实例，退出不承诺持久保存。

### 影音播放

本地音频/视频列表、类型筛选、刷新、播放暂停、上一首下一首、点按或拖到目标位置再松手跳转、音量、单次/单曲/列表循环、倍速、展开视频。使用 QtMultimedia MediaPlayer/VideoOutput，等比例显示。第一版离开播放器即停止，不提供后台音乐。

默认自带 **自制 8 秒 MP3 测试音与 H.264/AAC 测试视频**，不会自动播放，初始音量 25%。不同格式、硬件解码、蓝牙/耳机路由和倍速效果仍待实机验证；失败会保留错误，不能因文件扩展名支持就断言成功解码。

把自己的可信短媒体放到本包 `media` 文件夹：每个不超过 16 MiB，每次自动推送合计最多 32 MiB，超限文件跳过并记录。也可由有经验用户提前把媒体放到笔的 `/mnt/data/p011-media/`，本工具只列该目录下的普通媒体文件，不递归、不扫描其他资料、不跟随文件符号链接。程序不删除用户媒体。

### SSH 连接

电脑存在 `ssh-keygen.exe` 时自动生成/复用专用 Ed25519 密钥对，路径 `D:\project\P011\keys\p011-tools-client-ed25519`，只传公钥。私钥仅留电脑并收紧该文件 ACL；找不到工具或密钥准备失败时显示 `SSH_KEY_WARNING`，不自动安装软件，其他工具仍可测试。

笔上按钮可选择仅 USB（监听 127.0.0.1:2222）或当前 Wi-Fi 私网 IPv4（2222），均需点击确认。不会自动开放 SSH，不监听所有网卡，不回退到 4G。密码登录、空密码、转发和隧道均禁用，只使用公钥 root 登录。原厂系统账号若被锁或认证政策阻止，不会修改 `/etc/shadow` 来强行允许。

独立配置与主机密钥放 `/run/p011-tools-ssh/本次会话/`，不更改 `/etc/ssh`、既有 authorized_keys 或其他 SSH 服务。运行最多五分钟，或本次菜单试验结束时关闭服务及已识别会话。测试入口只做 `id; uname -a`，实际登录成功须以 `SSH_LOGIN_CONFIRMED` 和输出为准；“SSH 已开启”只代表进程状态。

用户在 root SSH 中刻意另起脱离会话的任务不由此工具保证终止。不要在公共网络使用 Wi-Fi SSH，不向公网暴露 root 服务。

## 自动记录

页面首次进入、操作和约每 15 秒保存应用 QML 项截图，最多 100 张；不是物理全屏录像。联网网页自动截图关闭。原厂或视频合成路径不同可能导致截图未包含全部外部图层，需结合现场观察。

结果位于：

```
D:\project\P011\logs\ToolsTest-Run-时间\
D:\project\P011\results\P011-ToolsTest-Run-时间.zip
```

截图、页面事件、原厂候选日志、桥接日志、电池采样、无线电快照、功能依赖及恢复结果会自动拉回。ANSI 颜色控制码只在统计时去掉，原日志保留。未访问页面标记“未观察到”，不是失败，也不冒充通过。

SSH 客户端检测结果在当前 Run 日志中追加；如果 Run 已结束，再双击 Collect 补取。私钥、API token、生成的 Session.js、完整进程环境和 USB 原配置备份不进入结果包。诊断仍可能包含 SSID、MAC、IP 和原厂业务日志，请分享前检查。

## 恢复与限制

原厂可执行文件、原启动脚本不覆盖。结束时先清理候选、停止本次服务、恢复本次改动的 USB 配置，再恢复原厂循环，并核对文件哈希和原版进程。工具恢复遇到冲突会明确报错，不通过吞掉错误冒充完成。

这是同一设备数据区里的试验，不是用户数据沙箱；原厂业务代码可能联网/写普通配置。内核卡死、硬件故障或所有恢复进程同时被终止不能靠脚本保证恢复，必要时用正常开机方式恢复，不刷写或格式化。测试期间保留 USB，勿重启。

已验证的旧基础：原厂菜单加载外置 QML、页面与截图、手动 Stop 后恢复。新加入的六页、HTTP 桥、SSH、媒体与本版 Windows 启动器仍须本次实机验证。离线/主机模拟测试结果位于 `docs/validation.json`，不替代 P011 Qt 5.10.1 实测。

## 建议验收顺序

先电池/无线电，再本地主页浏览器、MP3和视频；然后 SSH USB 开启 + 电脑 SSH-USB.cmd；最后 ADB “保存关闭 → 恢复原配置”，整个过程不要重启。测试完让十分钟计时恢复，或双击 STOP；把最终一个 ZIP 发回分析即可。

## v0.4.2 主机打包兼容修复

仅修复 Windows 端结果打包：显式加载 `System.IO.Compression` 并使用完整类型名 `System.IO.Compression.ZipArchiveMode`，解决 PowerShell 7 某些环境中的 `Unable to find type [IO.Compression.ZipArchiveMode]`。设备端 QML、工具后端和菜单候选与 v0.4.1 相同。启动器会在访问 ADB 之前先执行结果打包自检；若自检失败，不会切换学习笔界面。
